# quoteiq-business-calculator
Interactive ROI calculator showing home service pros how much time and money they waste without QuoteIQ

## Atlas prospecting map — 2026 UI redesign

`atlas-demo.html` is the Atlas commercial-prospecting map, restyled into a bright,
premium light/white interface (July 2026) over a light CARTO Positron basemap. Open it
in a browser to explore. All product behavior is unchanged from the reference demo — only
the UI was redesigned.

See [`DESIGN-NOTES.md`](./DESIGN-NOTES.md) for what changed and how to rebuild
(`design/` holds the editable design system and a deterministic assembler).
